> 推荐环境：Nginx + PHP≥7.0 + Linux

#### windows:
- 下载 PicLite [最新版](https://github.com/Lau0x/piclite/archive/refs/heads/main.zip)|[稳定版](https://github.com/Lau0x/piclite/releases) 上传至web根目录

#### Linux:

- `git clone https://github.com/Lau0x/piclite.git` 至安装目录

- 赋予安装目录www:www和0755权限:
```shell
chmod -R 755 /安装目录
chown -R www:www /安装目录
```
- 有条件的建议开启OPcache

#### BT宝塔面板
- 1. 推荐优先使用 Docker 部署；如使用面板安装, 请选择 PHP 8.3 并绑定网站目录
- 2. 使用上边的`Linux`方法搭建
- 3. 有条件的建议开启OPcache
